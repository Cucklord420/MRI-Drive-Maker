OPEN: START-MRI-DRIVE-MAKER.cmd
Right-click it and choose Run as administrator.

1. Menu 1: choose the extracted MRI folder. Its contents will go directly
   to each USB root. Actual ISO and ZIP files are supported too.
2. Menu 2: check the USB list, then enter the intended disk numbers
   separated by commas, for example 6,7,8.
3. Type the displayed ERASE confirmation. ALL files and partitions on
   these selected USBs will be deleted. No registration is needed.
4. Keep them connected until READY. The batch ends when each selected
   drive succeeds or fails. Use Windows Safely Remove before unplugging.
   Q cancels unfinished builds.

New settings allow 4 builds at once. Menu 4 changes the limit to 1-30.
Existing saved limits are preserved. Waiting selected drives start as slots
open. Shared USB bandwidth limits speed.

The selected folder is copied exactly to the root, without a wrapper.
Preparation creates active MBR/FAT32 using up to 32,000,000,000 bytes.
Every target file receives SHA-256 verification after writes are flushed.
System, source and application disks are excluded. Serial-less USBs
can be selected once in menu 2 using an unambiguous Windows connection
path. Never unplug, swap or move a serial-less drive during the batch;
port identity does not prove permanent hardware identity. Changed disk
numbers or connection paths fail, and automatic registration still
requires a usable hardware serial.

A Advanced retains the registered-drive automatic watcher. That mode
still blocks unexpected files and does not inherit a batch's erase approval.

App contains editable source and tests. Open only the top-level launcher.
Original sources, old launchers and historical reports stay on GitHub.

READY confirms file copying, not a firmware boot test. No proprietary MRI
files or BDE-to-USB utility are included. Use an authorized source.
