OPEN THIS FILE TO RUN THE TOOL:
START-MRI-DRIVE-MAKER.cmd

Right-click it and choose Run as administrator.

1. Choose 1 in the menu and select your official MRI .iso file.
   A .zip archive or an already-extracted folder is also supported.
   The ISO is opened read-only. You do not need to run a batch file.
2. Choose copy mode for empty FAT32 drives, or prepare mode to format
   individually registered MRI drives as MBR/FAT32.
3. Choose 2 to register the intended physical USB drives once.
   Check their hardware serials. Prepare mode requires ERASE confirmation.
4. Choose 4 to watch. Plug in registered drives; verified drives show READY.
   Use Windows Safely Remove before unplugging. Q stops the watcher.
