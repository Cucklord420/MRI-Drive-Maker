# Source downloads

[Download v0.3.0](https://github.com/Cucklord420/MRI-Drive-Maker/raw/refs/heads/main/downloads/MRI-Drive-Maker-v0.3.0.zip). Extract it, then open **START-MRI-DRIVE-MAKER.cmd** using **Run as administrator**. Select your source, enable preparation for the FAT32 clean/format/copy workflow, and register only the intended physical USBs. New configurations run four builds concurrently; menu **5** selects **1–30**. Existing limits are preserved. Checksums are in [SHA256SUMS.txt](SHA256SUMS.txt).

The actual MRI payload and BDE-to-USB program are not included. Physical MRI booting and exact BDE-to-USB equivalence have not been verified. Source, license, tests, and historical Git provenance are included.

Older archives are retained for history. v0.1.0 has a startup error; v0.1.1 fixes startup but lacks the new direct-copy recipe and audit fixes. Use the current archive in a separate extracted folder.
