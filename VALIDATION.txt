The final archive is checked separately after packaging the evidence.
The Windows storage check mounts a real test ISO, creates/formats only its own
file-backed VHD, copies via native Unicode Windows file APIs into a volume GUID,
verifies hashes, flushes the volume, checks reinsertion, and preserves unexpected files.
Only USB classification is mocked for that VHD; the erase guard rejects the VHD.
Two real copy failures were exposed and fixed: Robocopy error 53/exit 16 on a
volume GUID, then managed recursive directory creation rejecting the same path.
The fixed copy worker retains job containment, cancellation and timeout checks.

Before the new fixes, the old module passed 48 existing simulated cases but failed
both added regressions: no-batch copying and cancellation before raw-drive formatting.
Only simulated storage was used for that failure reproduction. The corrected
56-case suite passes locally on PowerShell 7.6.6/Linux and on Windows 5.1 above.
No physical USB, actual MRI source, BDE-to-USB program, Windows 10/11 workstation,
Secure Boot or firmware boot has been tested. READY means verified files and
accepted write flush, not a demonstrated bootable MRI drive or BDE equivalence.
